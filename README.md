# Tubestock Pals

A real-time pocket-pet nursery game. Propagate WA native plants from the Native Plant Propagation Guide, keep them watered, fed and weeded, and level up to unlock rarer species.

Play: https://mdonald91.github.io/Tubestock-pals/

## Files
- `index.html` – the whole game (plants, art, rules)
- `manifest.webmanifest` – app name, colours and icons for "Add to Home Screen"
- `sw.js` – lets the game work offline
- `icons/` – app icons

## Updating
Edit `index.html` on GitHub (pencil icon) and commit. The live game updates within a minute or two; reopen the app to get the new version.

Progress is saved in each player's own browser.
